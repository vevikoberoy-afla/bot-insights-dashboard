0.2 — TYPOGRAPHY
----------------------------------------------------------------
Font pairing:
- Display/headings: Geist Sans, font-weight 500-600
- Body: Geist Sans, font-weight 400
- Data/IDs/code snippets: Geist Mono, font-weight 400

Type scale:
- Page title (h1):   text-xl font-semibold tracking-tight text-ink
- Section title (h2): text-sm font-semibold text-ink uppercase tracking-widest
- Card title:         text-sm font-medium text-ink
- Body:               text-sm text-ink/80
- Meta/label:         text-xs text-ink-secondary
- Monospace data:     text-xs font-mono text-ink-secondary

Rule: No bold body text. Use font-medium (500) for emphasis.
Rule: All section headings use uppercase + tracking-widest.
Rule: Page titles are never larger than text-xl.
----------------------------------------------------------------

0.3 — SPACING & LAYOUT
----------------------------------------------------------------
- Sidebar width: 240px, fixed, full height
- Content area: flex-1, min-h-screen, overflow-auto
- Page padding: p-8 (desktop), p-4 (mobile)
- Section gap: space-y-8 between major sections
- Card gap: gap-4 inside grids
- All border-radius: rounded-lg (8px) — no rounded-full, no rounded-xl
  Exception: status badges use rounded-full
- All cards: border border-surface-border bg-surface shadow-none
  Hover: bg-surface-muted transition-colors
- No drop shadows anywhere except modals (shadow-lg)

SECTION 14: INTERACTION RULES
================================================================

Navigation:
- Clicking a sidebar parent item (with children) expands it in place.
  It does NOT navigate. Only sub-items navigate.
- Clicking a sidebar item with no children navigates directly.
- Active route highlights both parent and sub-item.

Transitions:
- Page transitions: none (instant, not distracting)
- Sidebar expand/collapse: 150ms ease-out
- Modals/sheets: 200ms slide-in from right (sheet) or fade (dialog)
- Status badges: no animation
- Skeleton → content: opacity fade 200ms

Feedback:
- All form submits: show loading spinner in button, disable button
- Success: sonner toast, top-right, green, 3 seconds, no icon
- Error: sonner toast, top-right, red, 5 seconds
- Destructive actions: always require shadcn confirm dialog first
- Clicking copy buttons: brief "Copied!" tooltip (shadcn Tooltip)

Responsive:
- Sidebar collapses to icon-only (56px) on tablet (< 1024px)
- On mobile (< 768px): sidebar becomes a bottom drawer (shadcn Sheet)
- All KPI card grids: 4 cols → 2 cols → 1 col
- Campaign/Bot card grids: 3 cols → 2 cols → 1 col
